# Savyly for Mac and Windows

A private AI assistant that floats over any app and stays off screen share. Type a question, answer what's on your screen with one key, or turn on listening and answer what was just asked in a call or video.

## Download

- **Mac:** **[⬇ Download Savyly.dmg](https://github.com/yprashanna/savyly-releases/releases/latest/download/Savyly.dmg)**. Needs an Apple Silicon Mac (M1 or newer) with macOS 13 Ventura or later.
- **Windows:** **[⬇ Download SavylySetup.exe](https://github.com/yprashanna/savyly-releases/releases/latest/download/SavylySetup.exe)**. Needs 64-bit Windows 10 (version 1809 or newer) or Windows 11.

Both links always get the latest version.

## Install on Mac

1. Open `Savyly.dmg` and drag **Savyly** into **Applications**.
2. Open Savyly from Applications. If macOS says it can't verify the developer, open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only need to do this once.
3. In the Savyly window, click **Allow** for Accessibility and switch Savyly on. For screen answers and listening, also allow **Screen & System Audio Recording**.
4. Click **Start assistant**, then press **⌘⇧Space** anywhere to ask your first question.

## Install on Windows

1. Run `SavylySetup.exe`. If Windows SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**. No admin rights are needed.
2. Savyly opens when setup finishes. There's nothing to allow.
3. Click **Start assistant**, then press **Win+Shift+Space** anywhere to ask your first question.

## Keys

| | Mac | Windows |
|---|---|---|
| Show or hide Savyly | ⌘⇧Space | Win+Shift+Space |
| Answer what's on your screen | ⌘⇧↩ | Win+Shift+Enter |
| Turn listening on or off | ⌘⇧L | Win+Shift+L |
| Answer the last question heard (while listening is on) | ⌘↩ | Win+Enter |
| Stop the answer | Esc | Esc |
| Scroll the answer (while Savyly is on screen) | ⌘↑ / ⌘↓ | Ctrl+↑ / Ctrl+↓ |
| Move the window (while Savyly is on screen) | ⌃ + arrows | Alt + arrows |

Listening hears your computer's own audio, like a call or a video. It never uses the microphone, and it's off until you turn it on. Type `/` in the question box to see commands such as `/mode` and `/new`.

## Updating

From version 0.3.2, Savyly updates itself: when a new version is out, click **Update** in the Savyly window, or type `savyly update`. Your settings and permissions stay. On 0.3.1 or older, download once from the links above.
